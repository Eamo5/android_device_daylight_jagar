# Android Device tree for the Daylight DC-1 (jagar)

Baseline LineageOS 23.2 bring-up tree for Daylight DC-1, based on the
MediaTek MT8781/MT6789-family jagar reference tree and stock jagar OTA images.

This is intentionally conservative: radio, NFC, camera, Wacom/display tuning,
and proprietary blob specialization should be validated against stock images and
the connected device before being enabled beyond the minimal baseline.
